## 已知限制

- 插件代码与内建工具同进程执行（目录放置即信任），沙箱只约束 bash 子进程，不约束插件 Python 代码；插件 v1 仅贡献工具，单文件模块。
- `workspace-write` 依赖平台后端（macOS `sandbox-exec`、Linux `bwrap`）；缺失时 bash 对受限策略直接拒绝。
- checkpoint 是"最近写入"LIFO 回退，不绑定会话或轮次，也不覆盖 bash 写文件。
- 缓存复用止于观测与稳定前缀保护；provider 侧缓存开关不在本层控制。
- Web UI、跨进程恢复、长期记忆、费用估算仍不在范围。
