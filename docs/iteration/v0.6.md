## 1. 定位

v0.6 不引入新执行范式,只让已有承诺成立:安全确认环真的能拦住危险命令、
预算门禁真的能判定超限、索引真的增量更新。三项变更独立可发布、可回滚。

## 2. 交付范围

| 变更 | 解决的问题 | 主规格 |
|---|---|---|
| `security-classification-hardening` | 包装器前缀绕过、命令替换未展开、敏感路径误杀、只读搜索工具无边界、越界警告丢失 | `tools` |
| `context-accounting-fidelity` | bash 双流合并无上限、中文 token 四倍低估、结果裁剪按字符硬折算 | `tools` `context-budget` |
| `session-index-incremental` | 追加路径先写后读导致索引永远重建(O(n²)) | `sessions` |

## 3. 关键实现

- `tools/security/wrappers.py`:包装器语义跳过(`timeout`/`nice`/`env`/`xargs`/`stdbuf`/`time`/`nohup`/`command`/`builtin`/`exec`),按选项表与固定操作数前进到真实命令;无法判定时返回"无命令"交由上层保守处理。
- `tools/security/interpreters.py`:解释器家族归一(去目录与版本后缀)与内联标志识别(`-lc` 视为含 `c`)。
- `tools/security/bash_rules.py`:命令替换任意位置展开(含 `foo=$(...)` 与 `${...}`),未闭合即拒绝。
- `tools/security/filesystem.py`:敏感目标拆成"明确目标"与"凭据文件名"两类,后者只在路径形态下生效;模板文件白名单。
- `tools/security/classifier.py`:ask 规则同时检查原始与去包装视图,既保留 `sudo`/`xargs` 规则,又能命中被包装的真实命令。
- `core/contracts/ports.py` + `core/orchestration/tool_call.py`:`ToolDecision.warning` 打通到工具结果文本(`[安全提示]` 单行前缀)。
- `tools/shared/merged.py`:合并输出统一上限,保留末尾,`truncated_by=merged_budget`,`incomplete`(超时/清理不确定)不被覆盖。
- `core/context/tokens.py`:中英混合估算;CJK 按字、ASCII 聚合后 `// 4`、其它非 ASCII 按 2 字符/token。预算与压缩共用。
- `core/context/governance.py`:工具结果裁剪改为按估算 token 二分收敛,从 `budget.py` 拆出以守住 300 行门禁。
- `session/persistence/jsonl/writing.py`:`_append` 改为"锁内读索引 → 应用记录 → 写 JSONL → 刷新指纹";索引缺失时回源一次。

## 4. 实测对比

| 场景 | v0.5 | v0.6 |
|---|---|---|
| `timeout 5 rm -rf ~` | allow | deny |
| `nice -n 5 rm -rf ~/d` | allow | ask |
| `env -i rm -rf /tmp/x` | allow | ask |
| `bash -lc 'rm -rf ~'` | allow | deny |
| `foo=$(rm -rf ~)` | allow | deny |
| `echo secret` / `grep -r SECRET src` / `cat .env.example` | deny | allow |
| `grep ~/.ssh` / `find /` / `ls ~` | allow(无提示) | deny / allow+warning / allow+warning |
| 40KB stdout + 40KB stderr | 60073 字符 | ≤30000 字节,`merged_budget` |
| 50 个中文字符 | 12 tokens | 42 tokens |
| 1000 次 append | ≈7s | 0.37s |

## 6. 已知限制与后续

- 分类器仍是静态判定,不是执行时隔离;沙箱(`read-only`/`workspace-write`/`full`)属 v0.8。
- token 估算仍为启发式,未接 provider tokenizer 或用实际 usage 反推系数。
- 测试窗口参数因估算口径变化而等比放大,属于口径调整而非断言放宽。
- `steer`/`followup` 仍未接入 TUI、无后台作业、事件流未对外导出——这些属于 v0.7 执行控制主题。
